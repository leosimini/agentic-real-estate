# MVP product scope

## Consumer

- Natural-language search intent.
- Structured filter editing after AI interpretation.
- Opportunity list with match score and freshness.
- Canonical property page with all detected publications.
- Save and dismiss with reason.
- Persistent hourly/daily/weekly monitors.
- In-app digest and exceptional-change alerts.
- Basic side-by-side comparison.

## Private publisher

- Create sale/rent publication.
- Upload data and media metadata.
- AI-assisted description as a later MVP increment.
- Manage publication state.

## Operator

- Professional profile.
- Create publication.
- Claim an aggregated publication after verification.
- Correct structured listing data.
- Receive direct lead conversation events.

## Admin

- Source health.
- Duplicate review queue.
- Publisher verification queue.
- Job failures and retries.
- Audit trail.

## Explicitly later

- Mortgage marketplace.
- Transaction closing workflow.
- Automated legal advice.
- Full CRM.
- Paid boosts and billing.
- Automated scraping of sources without a permitted access path.
- Computer-vision photo grading.
