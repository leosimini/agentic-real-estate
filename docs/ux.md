# UX direction

## Navigation

Mobile bottom navigation: Discover, Monitors, Publish, Saved, You.
Desktop promotes the same information architecture into a left rail and wider comparison workspace.

## Discover

The first control is an intent composer. The system extracts structured criteria and lets the user edit them. Results prioritize reasons, freshness, price movement, duplicate-publication count, and personal fit before secondary listing metadata.

## Opportunity card

Required visible fields:

- canonical price and currency
- rooms and total area
- personal match score
- one high-signal reason
- publication count
- verification freshness
- save, dismiss, compare, ask

## Opportunity detail

Order:

1. Media and canonical facts.
2. Why it fits.
3. Potential concerns.
4. All source publications and direct provenance URLs.
5. Price and publication history.
6. Location analysis.
7. Ask AI.

## Monitor

A monitor is a persistent search agent, not a saved filter. Its screen shows current criteria, last run, next run, meaningful changes, suppressed noise count, and controls for cadence and exceptional alerts.

## Publishing

The universal Publish action branches into owner listing, operator listing, and buyer demand opportunity. Use progressive disclosure. Do not ask for fields the system can infer or enrich later.

## Interaction principles

- Keep AI output editable and attributable.
- Always distinguish facts, model estimates, and user preferences.
- Make freshness visible.
- Never hide source provenance.
- Use dismiss reasons to improve ranking.
- Prefer concise daily digests over notification volume.
